# Supernova

> A lightweight hobby trainer that takes the grind out of repetitive in-game tasks.

Supernova is a personal side project built to automate the tedious, repeat-every-session chores that eat up play time: farming loops, collecting resources, clicking through menus, and similar routines. Set it up once, let it run, and spend your time on the parts of the game you actually enjoy.

---

## Usage

1. Start the game you want to use Supernova with.
2. Launch Supernova and pick (or create) a profile.
3. Choose a routine from the menu, or build a new one from the available actions.
4. Press the **Start** hotkey to begin. Press **Stop** at any time to end the routine.
